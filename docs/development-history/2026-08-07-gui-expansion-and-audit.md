# 2026-08-07 작품 관리, 확장 기능과 최종 안전 감사

## 기준

- 날짜: 2026-08-07
- 커밋 범위: fc3d2d6 ~ 338850c
- 커밋 수: 101개
- 문서화 시작 직전 HEAD: 338850c

이 날의 작업은 작품 단위 저장 모델을 완성하고, 사용자가 제공한 Hitomi Downloader 참고
화면에서 개인용 tokiDownloader에 유용한 기능을 선별해 공용 서비스, CLI, 테스트와 GUI에
수직으로 연결한 과정이다.

## 개발 원칙

- 작품 한 개는 목록 행 한 개로 유지하고 실행 이력은 별도로 누적한다.
- GUI 버튼과 메뉴는 공용 서비스를 거쳐 같은 CLI 또는 상태 JSON으로 검증한다.
- 실제 다운로드 파일 삭제와 기록 정리를 분리한다.
- 파일 변경 작업은 dry-run, 대상 검증과 사용자 확인을 먼저 제공한다.
- Qt 메인 스레드에서 네트워크, 대량 파일 검사와 이미지 디코딩을 수행하지 않는다.
- I/O는 제한된 스레드 풀, CPU 작업은 제한된 프로세스 풀을 사용한다.
- 브라우저, 콘솔과 작업자 프로세스는 기본적으로 보이지 않게 실행한다.
- 접근 제한 우회, 개인 Chrome 프로필 자동 사용과 인증 정보 노출은 구현하지 않는다.

## 핵심 기능과 근거

### 작품 단위 목록과 실행 이력

- fc3d2d6에서 사이트 종류와 작품 ID로 work_key를 만들고 고유 인덱스와 upsert를 적용했다.
- 같은 작품을 재실행해도 새 작품 행을 만들지 않고 기존 작품 상태를 갱신한다.
- 21285ad와 7d12d13에서 작품별 실행 이력, 실행별 로그와 상세 화면을 추가했다.
- 기록 제거는 실제 다운로드 파일을 지우지 않는다.
- 단일 클릭은 선택, 더블클릭은 폴더 열기, 우클릭은 실제 동작 메뉴로 구분했다.

### 재검사와 재시도

- f15bfef에서 신규 회차, 전체 재검사와 범위 재검사를 별도 의미로 분리했다.
- 신규 회차 검사는 사이트 목록을 다시 읽고 실제 완료 회차만 제외한다.
- 전체와 범위 재검사는 선택 범위를 다시 점검하되 이미 정상인 파일은 다운로드 엔진에서
  건너뛴다.
- 중단 작업 복구, 자동 재시도 횟수와 지수 백오프, 인증·네트워크 오류 분류를 추가했다.
- 작품별 중지, 대기열 취소, 일시정지·계속과 우선순위 변경을 CLI와 GUI에 연결했다.

### 저장 폴더와 파일 도구

- 기본 폴더명 템플릿은 [{author}][{group}] {title}이다.
- 작품 폴더 이동은 충돌과 경로 경계를 먼저 검사하며 미리보기를 제공한다.
- metadata.json 재구축, 대표 이미지 열기·갱신, 회차·이미지 파일 검사를 제공한다.
- 이미지 변환·리사이즈·회차별 PDF는 원본 보존을 기본으로 하고 취소와 임시 파일 복구를
  지원한다.
- 압축파일 검사는 선택 의존성으로 분리했다.

### GUI와 개인용 사용성

- 창 크기, 위치, 최대화 상태와 다중 모니터 화면 경계를 복원한다.
- 밝은·어두운·시스템 테마, UI 배율, 글꼴, 배경과 목록 밀도를 설정할 수 있다.
- 목록·아이콘 보기, 썸네일, 빠른 실행 막대, 트레이, 알림과 단축키 편집을 추가했다.
- 클립보드의 지원 URL은 작품 키로 중복을 판정한 뒤 사용자가 확인해 추가한다.
- GUI 상태와 화면을 CLI에서 조회·캡처·닫을 수 있다.
- 76b5a93에서 EtaSwCwj.tokiDownloader.GUI.1 AppUserModelID와 전용 아이콘·앱 이름을 적용해
  다른 PyQt 프로그램과 작업 표시줄에서 구분했다.

### 성능과 안정성

- SQLite 인덱스 검색·정렬·페이지 조회와 model/view 기반 목록을 유지한다.
- GUI 상주 행, 썸네일 메모리·디스크 캐시, 로그와 하위 프로세스 버퍼에 상한을 둔다.
- 고빈도 진행 이벤트를 병합해 UI와 DB 갱신 빈도를 제한한다.
- 작품 동시 작업 수와 작품 내부 이미지 동시성을 별도로 제한한다.
- I/O 스레드 수와 CPU 프로세스 수를 설정 가능한 안전 범위로 제한한다.
- 강제 종료 뒤 작업 상태와 SQLite 무결성을 복구하는 검사를 추가했다.

### Hitomi 선택 공급자

- Hitomi와 ExHentai URL·ID 분석, 서버 선택, 메타데이터 조회·정규화를 구현했다.
- 파일명, 제외 태그, 일본어 제목, metadata.json·info.txt와 원본 이미지 선택 정책을
  서비스·CLI·GUI에서 관리한다.
- 메타데이터 HTTP 리다이렉트를 같은 출처로 제한하고, 자격증명 목적지 호스트가 다르면
  보안 저장소를 읽기 전에 쿠키 사용을 거부한다.
- 기존 ltn.hitomi.la가 더 이상 해석되지 않아 ltn.gold-usergeneratedcontent.net 기반
  메타데이터 엔드포인트로 갱신했다.

이 범위는 정책과 메타데이터 처리까지다. Hitomi 이미지 파일을 내려받는 전체 공급자
파이프라인을 완료했다는 의미는 아니다.

### YouTube 선택 공급자

- simulate 모드는 yt-dlp, 네트워크와 파일 생성 없이 같은 작업 수명주기를 검사한다.
