## 해결하려던 사용자 문제

기능이 늘어나는 동안 메인 화면에 저장 경로, 회차 범위, 동시성, 브라우저, 재시도와 빠른
실행 버튼이 모두 펼쳐져 작품 목록보다 입력·설정 영역이 더 복잡해졌다. 작품 우클릭 메뉴도
열기, 재검사, 파일 검사, 변환, 메타데이터, 정리, 복사와 작업 제어가 한 단계에 길게
나열되어 필요한 항목을 찾기 어려웠다.

사용자가 원하는 동작은 기능 삭제가 아니라 다음과 같은 재배치였다.

- 자주 바꾸지 않는 동시성, 재시도와 브라우저 표시는 설정 창에서 관리한다.
- 메인 화면은 URL, 저장 위치와 다운로드 중심으로 간결하게 유지한다.
- 회차 검사 옵션은 필요할 때만 펼친다.
- 기존 빠른 실행 기능은 여러 버튼 대신 한 개의 메뉴로 보존한다.
- 우클릭 기능은 목적과 현재 작업 상태에 따라 묶고, 사용할 수 없는 작업은 늘어놓지 않는다.
- GUI에서 옮기거나 묶은 기능도 기존 CLI 제어와 자동 검증 경로를 유지한다.

## 구현 내용

### GUI

- 메인 입력부는 항상 보이는 URL, 저장 폴더, 다운로드, 빠른 실행 메뉴와 다운로드 설정
  진입점 중심으로 줄였다.
- 검사 방식과 시작·마지막 회차는 `검사 옵션`을 눌렀을 때만 보이는 접이식 영역으로
  옮겼다. 지정 범위가 아닐 때 회차 입력이 실행에 섞이지 않는 기존 의미는 유지했다.
- 작품·이미지 동시성, 자동 재시도 횟수와 브라우저 표시 여부를 메인 입력 위젯에서
  제거하고 설정 창의 네트워크 탭 한곳에서만 편집하게 했다.
- 현재 다운로드 설정은 `작품 N · 이미지 N · 재시도 N회 · 브라우저 표시/숨김` 한 줄
  요약으로 보여준다. `다운로드 설정...`은 설정 창의 네트워크 탭을 바로 연다.
- 가로로 나열하던 빠른 실행 막대는 `빠른 실행` 드롭다운으로 바꿨다. 디스플레이 설정에서
  선택한 항목과 순서, 기존 QAction의 활성 상태와 실행 경로는 그대로 사용한다.
- 저장 폴더 선택과 열기, 작업 목록, 검색·상태 필터·정렬, 실행 로그와 상태 표시줄은
  개인용 다운로드 작업에서 계속 필요한 정보이므로 메인 화면에 유지했다.

### 설정을 단일 실행 원본으로 사용

이전에는 설정 창의 값과 메인 화면의 동시성·재시도·브라우저 위젯이 같은 설정을 각각
보유했다. 실행, 상태 JSON과 종료 저장 코드가 메인 위젯 값을 다시 읽어 두 표현이 달라질
가능성도 있었다.

이번 변경에서는 `self.config`를 다운로드 기본값의 단일 실행 원본으로 사용한다.

- 설정 창 적용 결과를 `self.config`에 반영하고 메인 화면은 요약 문구만 갱신한다.
- 새 작업 생성, 작품 스케줄러, 재시도, GUI 상태 JSON과 종료 저장은 정규화한 config 값을
  읽는다.
- CLI로 동시성이나 재시도 정책을 바꿔도 같은 config와 요약이 함께 갱신된다.
- 메인 화면에서 제거된 위젯을 보이지 않는 값 저장소로 남기지 않았다.
- 새 설정 키나 DB 스키마는 추가하지 않았고 기존 개인 설정값을 그대로 사용한다.

### 작품 우클릭 메뉴 구조

메뉴 생성과 표시를 분리하고 각 QAction에 기계 판독 가능한 동작 ID를 붙였다. 공통 메뉴는
다음 순서로 정리했다.

1. 작품 정보 및 실행 이력
2. 다운로드 폴더 열기
3. 원본 페이지 열기
4. 현재 상태에 맞는 작업 제어 또는 재검사
5. 파일 및 회차 도구
6. 작품 데이터
7. 작품 정리
8. 복사
9. 목록 기록 제거

상태와 공급자에 따른 차이는 다음과 같다.

- 실행 중이면 일시정지와 중지만 `작업 제어`에 표시한다.
- 일시정지 상태이면 계속과 중지를 표시한다.
- 대기 작업이면 취소를 표시하고, 대기 작업이 여러 개일 때만 맨 앞·맨 뒤 이동을 표시한다.
- 실제 프로세스가 없는 `재시도 대기`에는 실행 불가능한 일시정지를 숨기고 중지만 표시한다.
- 실행 상태 문자열만 남고 실제 실행 컨텍스트가 없는 기록에는 재검사 대신
  `불완전 작업 복구...`를 표시한다.
- 실행 중이 아닌 toki 작품에는 신규·전체·현재 입력 범위의 `작품 재검사`를 표시한다.
- 실행 중이 아닌 YouTube 작업에는 만화 회차 재검사 대신 `작업 다시 시도`를 표시한다.
- 파일 검사·미리보기·중복 검사·변환·PDF는 `파일 및 회차 도구`로 묶었다.
- 대표 이미지와 메타데이터 동작은 `작품 데이터`로 묶었다.
- 고정·그룹·색상은 `작품 정리`, 작품명·URL·경로·ID는 `복사`로 묶었다.
- 파일을 지우지 않는 `목록 기록 제거...`는 맨 아래에 분리하고 작업 중에는 비활성화한다.

기능 자체와 사용자 파일 안전 규칙은 바꾸지 않고 표시 순서와 상태별 노출만 정리했다.

### CLI와 기계 판독 결과

- 기존 `job-menu --job 작업ID`는 실제 우클릭 메뉴를 여는 동작을 유지한다.
- `job-menu --job 작업ID --inspect`를 추가했다. 메뉴를 띄우지 않고 현재 작품 기준의
  `rootItems`, 모든 깊이의 `submenus`, `actionIds`, 항목별 `enabled`와 체크 항목의
  `checked` 값을 JSON으로 반환한다.
- GUI 상태 JSON의 `mainInputLayout`은 항상 보이는 항목, 접이식 항목, 설정 전용 항목,
  옵션 펼침 상태와 설정 요약을 제공한다.
- 메인 다운로드, 설정, 빠른 실행과 우클릭의 각 실제 기능은 기존 개별 CLI와 공용 처리
  메서드를 계속 사용한다.

### 자동 테스트

- 우클릭 메뉴 표시와 구조 검사가 서로 다른 IPC 동작으로 정확히 전달되는지 검사했다.
- `job-menu --inspect` CLI가 `inspect_job_menu` 요청을 보내는지 검사했다.
- 설정 창 적용과 CLI 설정 변경 뒤 config와 메인 요약이 함께 갱신되는지 검사했다.
- 동시 작품 스케줄러가 제거된 메인 위젯이 아니라 config 값을 사용하는지 검사했다.
- 기존 다운로드, 공급자, 파일 도구와 CLI 회귀 검사를 함께 실행했다.
