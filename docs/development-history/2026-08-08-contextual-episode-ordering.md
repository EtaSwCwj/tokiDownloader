# 2026-08-08 소수·분할 형제 회차의 조건부 정렬명

## 문제

전체 제목 기반 폴더로 이관한 뒤에도 문자열 정렬에서는 `141.5화`가 `141화`보다 먼저
보일 수 있었다. 다른 작품에는 `140화`, `140-2화`처럼 첫 분할 회차만 정수로 표기된
경우도 있다. 모든 정수 회차에 `.0`을 붙이면 하이픈 분할형과 합본까지 불필요하게
바뀌므로 작품의 형제 회차 문맥을 함께 봐야 한다.

## 저장 규칙

- 같은 접두·접미 문맥의 `N화`와 `N.x화`가 있으면 기본 회차만 `N.0화`로 바꾼다.
- 같은 문맥의 `N화`와 정확한 `N-2화`가 있고 `N-1화`가 없으면 기본 회차를 `N-1화`로
  바꾼다. 하이픈 주변 공백 형식은 `N-2화` 쪽을 따른다.
- 일반 정수 회차, 기존 소수·하이픈 회차와 `1~5화` 같은 합본은 보존한다.
- `R-18`, 인물명, 본편·부록처럼 숫자 앞뒤 문맥이 다르면 서로의 형제로 보지 않는다.
- `.0` 또는 `-1`이 이미 있거나 한 기본 회차가 소수형과 `-2`형을 동시에 요구하면
  자동 변경하지 않고 명시적 충돌로 중단한다.

## 구현

- Node 다운로더는 사이트에서 읽은 전체 회차 목록의 원문 접미사를 그룹화한 뒤 신규
  manifest의 표시명과 폴더명을 계산한다. 기존 state가 정확히 가리키는 폴더는 다운로드
  도중 자동으로 바꾸지 않고 명시 이관 기능에 맡긴다.
- Python `rename-episodes` 계획은 모든 기존 회차의 접미사를 먼저 추출한 뒤 같은 문맥
  분석을 수행한다. 계획 결과에는 적용 여부·이유와 문맥 충돌 코드가 포함된다.
- 실제 변경은 기존의 전체 충돌 검사, state·metadata 백업, 두 단계 임시 이름, 실패
  롤백 계약을 그대로 사용한다.

## 실제 작업 감사

작업 `54d3f0ed91`의 272개 폴더를 읽기 전용으로 조사했다.

- 소수 형제: `141화`와 `141.5화` 한 쌍
- `N-1` 또는 `N-2` 분할형: 없음
- `~` 합본: 12개
- ASCII 하이픈: 회차 구분자가 아니라 `R-18` 문맥에만 존재
- 조건부 계획: `141화 → 141.0화` 1개, 나머지 271개 유지, 충돌 0개
