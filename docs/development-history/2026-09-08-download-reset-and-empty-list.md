- 격리 CLI fixture는 실패 시 사용자 경로로 생산용 GUI를 시작할 수 없도록 막았다.

## 같은 날 후속: 이미지 TLS 초기 연결 복구

기준 커밋 `001abc9`. 사용자가 연결 문제 자체를 해결하라고 요청했다.

### 추가 진단과 수정 근거

- 일반 Node HTTPS 요청은 TCP 연결 이후 TLS 교환 단계에서 약 145~171 ms 만에 reset됐다.
- 같은 URL·인증서 검증·TLS 버전을 유지하고 ClientHello를 두 TLS 레코드로 나눈 요청은
  4회 연속 HTTP 200, 283,353바이트 응답을 받았다. TCP 분할만으로는 재발했다.
- 이는 초기 TLS 메시지를 처리하는 경로의 문제와 일치하지만 어느 장비/사업자가 끊는지는
  확정하지 않는다. TLS 1.2 강제 전환, 인증서 검사 해제, 임의 CDN 교체는 하지 않았다.
- 참고한 1차 자료: [Node TLS socket·인증서 검증](https://nodejs.org/api/tls.html#tlsconnectoptions-callback),
  [TLS 1.3 레코드 분할 규칙](https://www.rfc-editor.org/rfc/rfc8446#section-5.1),
  [GoodbyeDPI의 초기 연결 분할 설명](https://github.com/ValdikSS/GoodbyeDPI#how-does-it-work).
  GoodbyeDPI나 시스템 드라이버를 설치하거나 실행한 것은 아니다.

### 구현

- `downloader_transport.js`: 직접 HTTPS 요청이 **TLS 인증 완료 전 ECONNRESET**으로
  실패할 때만 한 번 초기 레코드 분할로 재시도한다. 바이트 내용과 이후 암호화 데이터는
  변경하지 않으며 기본 TLS·인증서·호스트 이름 검증을 유지한다.
- 프록시가 설정된 경우 직접 연결 fallback을 하지 않는다. HTTP 오류나 인증서 오류,
  TLS 연결 이후 전송 reset도 이 fallback의 대상이 아니다.
- 성공한 origin은 현재 실행에서 최대 128개 기억하며 정상 연결/호환 연결 풀 각각 소켓
  상한 16개, 유휴 소켓 상한 4개를 둔다. 사용자 이미지 동시성, 요청 간격과 전송 속도
  제한은 유지한다. 의도된 대역폭 제한 대기를 네트워크 timeout으로 잘못 세지 않는다.
- DNS/연결/TLS 대기에 제한 시간을 적용하고, 응답은 128 MiB 상한으로 제한한다.
  HTTP 리디렉션 5회 제한과 원자적 이미지 검증·저장은 유지한다.
- GUI/CLI는 같은 `down.js` 경로를 사용한다. 새 설정이나 사용자 추가 조작은 필요 없다.
- 실제 장기 접속 검증에서 발견한 재사용 소켓의 `secureConnect` 리스너 누적도 수정했다.

### 검증

- 자체 서명 loopback TLS 서버와 첫 ClientHello를 reset하는 중계기를 테스트 안에 생성해
  실제 reset → 검증된 TLS 연결 복구 → 병렬 8장 → 추가 30회 연결 재사용을 검사했다.
  테스트 인증서는 해당 테스트 인스턴스만 신뢰하며 시스템 신뢰 저장소는 변경하지 않는다.
- 잘못된 인증서와 호스트 이름 거부, HTTP 403 거부 유지, 프록시 reset의 직접 연결 금지,
  HTTP/리디렉션/대역폭 제한 대기/정지된 TLS timeout을 검증했다.
- 별도 검증 폴더의 26-2화 8장 + cover 다운로드 성공, 이미지 검증 통과, `completed`
  이벤트와 종료 코드 0을 확인했다. 전송 모듈 직접 호출도 3회 연속 유효 JPEG를 받았다.
- Node 67건, Python 394건 통과. 연결 중 취소와 캐시/연결 풀 상한 검사를 포함한다.
  자체 점검의 필수 파일/구문 검사에도 새 전송 모듈을 포함했다.
  실제 GUI 작업의 남은 회차도 같은 경로로 이어서 검증한다.
- 실제 `toki-cli self-test --core-only --json`도 5/5 항목 성공했다. 결과는
  `logs/self-test.json`에 기록했다. GUI 재시도 전후 원래 있던 26-2화 이미지 6장의
  SHA-256을 비교해 모두 그대로임을 확인했다.
