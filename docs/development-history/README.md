# tokiDownloader 개발 이력

이 폴더는 계획서의 체크박스나 Git 커밋 제목만으로는 남기기 어려운 개발 배경을 보존한다.
각 기록은 사용자가 겪은 문제, 선택한 해결 방향, 실제 구현 범위, 검증 결과와 남은 제한을
함께 적는다.

## 현재 개발 방향

2026-08-07 사용자 결정에 따라 이 프로젝트는 공개 배포용 제품이 아니라 한 명이 자신의
Windows 환경에서 안정적으로 쓰는 개인용 도구를 목표로 한다.

따라서 다음 항목을 우선한다.

1. 실제 toki 다운로드, 신규 회차 검사와 재시도가 정확하게 동작할 것
2. 기존 다운로드 파일과 메타데이터를 손상시키지 않을 것
3. GUI에서 필요한 기능을 쉽게 찾고, 같은 기능을 CLI로 재현·검증할 수 있을 것
4. 오류 원인을 화면·파일 로그·상태 JSON·프로그램 자체 캡처로 확인할 수 있을 것
5. 작품과 실행 기록이 많이 쌓여도 시작, 검색, 정렬과 스크롤이 느려지지 않을 것
6. Chrome이나 콘솔 창이 불필요하게 나타나 일상적인 PC 사용을 방해하지 않을 것

설치형 EXE, 코드 서명, 자동 업데이트, 공개 릴리스와 CI는 필요해질 때 별도로 추진한다.
현재 개인용 기능의 완료 여부를 판단하는 필수 조건으로 취급하지 않는다.

## 기록 원칙

개발 단위가 끝날 때 다음 내용을 남긴다.

1. 날짜와 시작·종료 기준 커밋
2. 해결하려던 사용자 문제
3. 공용 서비스, CLI, 테스트와 GUI에서 바뀐 내용
4. 중요한 설계 결정과 선택 이유
5. 사용자 파일, 설정, 인증 정보에 미치는 영향
6. 실행한 검증 명령과 실제 결과
7. 실행하지 않은 검증과 알려진 제한
8. 관련 커밋 목록

다음 표현은 섞어 쓰지 않는다.

- 구현됨: 코드 경로가 존재한다.
- 자동 검증됨: 단위·통합·CLI 또는 GUI 자체 점검이 통과했다.
- 라이브 검증됨: 실제 외부 사이트나 실제 파일을 사용해 확인했다.

설정에 토큰, 쿠키, 프록시 인증 정보나 개인 경로가 포함돼도 이력에는 값을 기록하지 않는다.
사용자 다운로드 파일을 변경하지 않은 dry-run과 실제 변경 실행도 명확히 구분한다.
