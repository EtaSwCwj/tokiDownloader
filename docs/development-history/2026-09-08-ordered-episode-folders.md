# 2026-09-08 원본 회차 폴더의 정렬 순번

## 문제와 변경

사용자가 지정한 이세계 개인방송 작품 폴더에는 `0001 축약 제목 1화`와
`전체 제목 2화` 형식이 섞여 있었다. 제목이 정렬 키의 앞에 있으므로 표기 변경에 취약하고,
문자열 정렬을 사용하는 뷰어에서는 2화보다 10화가 먼저 나올 수도 있었다.

- 새 회차 폴더의 기본 저장명: `000001 전체 제목 1화`.
- 앞의 6자리 번호는 사이트 전체 회차 목록의 읽기 순번이다. 실제 회차 표기는 끝에 유지한다.
  `000025 전체 제목 25-1화`, `000026 전체 제목 25-2화`처럼 분할 회차도 순서가 유지된다.
- 전체 제목 복원, 소수 회차가 있을 때만 기본 회차의 `.0`, 분할 `-2`가 있을 때의 `-1`
  처리는 기존 공용 접미사 규칙을 그대로 사용한다.
- `rename-episodes`와 GUI의 회차 폴더명 정리 기본값도 동일한 `ordered_title` 규칙이다.
  과거 title-only 이관 코드는 내부 `ordered=False` 호환 모드와 기존 회귀 검사로 보존한다.
- 기존 폴더를 다운로드 도중 몰래 이동하지 않도록 재개 시 존재하는 매핑은 재사용한다.
  다른 작품의 예전 폴더는 사용자가 해당 작품의 회차 폴더명 정리를 실행하면 일괄 변경된다.
- 실제 이관은 기존 두 단계 이름 변경/복구 절차를 사용한다. 상태·메타데이터뿐 아니라
  ZIP 카탈로그도 백업하고 원본 폴더 참조를 함께 바꾼다. ZIP 파일 내용은 변경하지 않는다.
- 충돌이나 카탈로그 저장 실패 시 폴더 및 메타데이터·카탈로그를 복구한다.


## 2026-09-10 후속: 사이트 순번과 감상 순서 분리

위의 초기 '사이트 목록 순번=읽기 순번' 정책은 이 절의 공통 감상 정렬 정책으로 대체한다.
러브 다이어리의 사이트 목록 자체가 본편1→외전1→본편2→외전2 순서였고, 기존 코드는 그 순번을
폴더/ZIP에 그대로 적용했다. 특정 작품 예외가 아니라 프로그램 전체의 기본 정렬 규칙으로 수정했다.

### 공통 정책

- `episode_reading_order_rules.json`은 분류어·숫자/단위 규칙·보류 안내를 정의한다.
  `downloader_reading_order.js`와 `toki_reading_order.py`가 이 정책을 읽으며 공통 사례와
  실제 Node↔Python 교차 출력 비교로 동일 결과를 검증한다. Qt 목록 표시에서는 계산하지 않는다.
- 본편 숫자순 → 외전/번외편/특별편/스핀오프/후일담 각 독립 그룹의 숫자순.
- `141화 외전`은 141화 뒤, `141.5화` 및 `140-2화` 등은 본편의 자연순 위치에 둔다.
  기존 `.0` 및 `-1` 형제 회차 제목 규칙은 유지한다.
- 번호 없는 항목, 해석이 모호한 독립 외전, 범위·부/시즌 표기는 인접 본편 정렬 구간의 기준점으로
  남긴다. 서로 다른 권/화 단위도 별도 구간이다. 판정 불가를 임의 화수로 바꾸지 않는다.
- 메타데이터 `number`는 사이트 순번, `readingOrder`는 감상 순번이다. ID와 완료 집합은 변경하지 않는다.
  `readingGroup`, `readingOrderVersion`, `readingOrderWarning`도 저장한다.
- 신규 저장 폴더는 감상 순번을 사용한다. 기존 매핑 폴더는 다운로드 중 몰래 옮기지 않고
  GUI/CLI의 공통 `rename-episodes` 트랜잭션으로 이관한다. ZIP은 전체 압축 시 동일 정책으로 갱신한다.
- ZIP만 남은 회차도 카탈로그의 고유 ID와 원본 제목으로 다시 정렬한다. 누락 회차가 나중에 추가되어도
  나머지 이미지 바이트를 보존하고 올바른 위치로 넣는다. 부분 회차를 완료/압축에 넣지 않는다.
- 검증된 기존 6자리 폴더에 축약된 원본 제목이 남아 있으면 제목을 새로 추측하지 않고 순번만 바꾼다.
  관련 없는 폴더나 ID가 불명확한 폴더까지 이 안전 예외를 확장하지 않는다.
- 폴더명 교환/순환의 대상이 모두 해당 트랜잭션 소유일 때만 허용한다. 복구 시에도 임시 이름으로
  먼저 되돌린 뒤 원래 이름을 복구한다. 관련 없는 대상 충돌은 계속 차단한다.
- 미수신 기록의 폴더 경로도 고유 ID로 갱신하며 실패 이미지 URL 등 진단 내용은 유지한다.
