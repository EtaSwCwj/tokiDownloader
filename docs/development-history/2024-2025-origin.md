# 2024~2025 원본 프로젝트 이력

## 범위

- 기간: 2024-08-23 ~ 2025-11-25
- 커밋: c84267c ~ 8e566b4
- 커밋 수: 21개

이 시기는 toki 계열 사이트의 작품을 내려받기 위한 JavaScript 도구가 만들어지고,
사용자 스크립트와 Node 다운로더 형태로 발전한 원본 프로젝트 단계다.

## 주요 변화

### 2024-08-23: 최초 스크립트와 사용법

- c84267c에서 다운로드 스크립트를 처음 추가했다.
- 1d5ad4e부터 a83927e까지 README, 사용 이미지와 안내 링크를 보강했다.
- dbdc79e에서 사용 문서를 다시 정리했다.

### 2024-08-25 ~ 2024-09-10: 프로그램형 다운로더

- 1ca839e에서 기존 스크립트를 수정했다.
- 3aabdd2와 2ab249d에서 프로그램으로 실행하는 다운로드 경로를 추가했다.
- a97fb94에서 사용 영상을 추가했다.
- ed1f7f6에서 처리 확장자를 넓혔다.

### 2025-04: 사이트 변화 대응

- 71ad4ba에서 page.waitForNetworkIdle 무한 대기를 제거하고, HTTP client가 막히는 상황을
  Puppeteer 기반으로 처리했다.
- 922e789와 f26c225에서 tokiDownloader.js를 사용자 스크립트 형태로 바꾸고 이미지·텍스트
  감지 범위를 개선했다.
- 94c049c와 9a5b1ee에서 다운로드할 수 없는 이미지와 정규표현식 예외를 처리했다.
- cb6cc3d에서 사용자 스크립트 아이콘을 변경했다.
- 438e4d2에서 배포 링크를 Sleazy Fork로 갱신했다.

### 2025-09 ~ 2025-11: 문서와 라이선스

- 21215f3에서 README를 갱신했다.
- 8e566b4에서 LICENSE를 추가했다.

## 이 단계에서 형성된 기반

- 브라우저 자동화를 이용한 toki 페이지 접근
- 이미지와 텍스트 회차의 기본 다운로드
- 사용자 스크립트와 Node CLI라는 두 가지 사용 방식
- 사이트 구조 변경에 맞춘 감지 규칙과 예외 처리

## 다음 단계로 넘어간 이유

원본 도구는 명령행과 브라우저 중심이어서 저장 폴더, 작품 메타데이터, 대표 이미지,
작품 단위 중복 관리와 실행 이력을 한 화면에서 다루기 어려웠다. 사이트 주소 형식도
newtoki 숫자.org/manhwa/작품번호 형태를 받아들이도록 갱신할 필요가 있었다.

이 문제를 해결하기 위해 2026-08-06부터 기존 Node 다운로드 엔진을 보존하면서 Python 공용
서비스, CLI와 PyQt6 GUI를 얹는 별도 개발 단계가 시작됐다.
